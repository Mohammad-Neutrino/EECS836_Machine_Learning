# ML Project (Radar Echograms)

Welcome to the main repository for **Machine Learning Project**, a graduate-level course at the University of Kansas. 

## 📦 Environment

The project uses:

- Python 3.8+
- PyTorch
- NumPy, Matplotlib
- OpenCV, scikit-image
- tqdm, seaborn

Install all dependencies via:

```bash
pip install -r requirements.txt
```
